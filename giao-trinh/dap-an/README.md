# Đáp án

Mở file tuần tương ứng sau khi test của mình đã chạy, hoặc sau khi đã có một bản tự viết và muốn so cấu trúc.

Chép nguyên file đáp án vào `src/` thì chưa tính là xong tuần. Đáp án dùng để thấy một cách đặt tên và một cách tách hàm. Phần figure của tuần 3, 4, 5, 7, 8 nằm ngay trong giáo án vì đó là khuôn cần có để làm được việc, không phải câu đố.
